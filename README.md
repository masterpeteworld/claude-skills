# Claude Skills

Personal library of Claude Code skills: marketing, growth, sales, SEO, and productivity.

## Install

Copy any skill folder into your project or user skills directory:

```bash
git clone https://github.com/masterpeteworld/claude-skills.git
cp -r claude-skills/.claude/skills/<skill-name> ~/.claude/skills/
```

Restart Claude Code. Skills load automatically when relevant.
