# Claude Skills

Personal library of Claude Code skills: marketing, growth, sales, SEO, and productivity.

## Install

On your Mac, once:

```bash
git clone https://github.com/masterpeteworld/claude-skills.git ~/claude-skills
~/claude-skills/skills.sh
```

To update later, run `~/claude-skills/skills.sh` again. It pulls the latest and copies every skill into `~/.claude/skills`.

- Only some skills: `~/claude-skills/skills.sh meeting-assistant ads`
- List skills: `~/claude-skills/skills.sh --list`

Restart Claude Code after installing. Skills load automatically when relevant.
